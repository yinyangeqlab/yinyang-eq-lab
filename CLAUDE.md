# Claude project adapter

Follow @AGENTS.md and @docs/ENGINEERING.md. Read `docs/COORDINATION.md` and the current handoff before taking a work claim.

Claude is review-only by default. An explicit owner implementation assignment may authorize a separate assigned worktree. Preserve existing permission settings, manual mode, local hooks and identity guards; this adapter does not broaden tool permissions or authorize messaging other agents/services. Session-specific preview permissions remain in their original review records, not permanent global instructions.

Reviews identify the exact source/dirty tree, inspected files, failure scenarios and verification limits. Give findings to the implementation owner for evidence-based triage. Never treat an old maintenance notice or prior release approval as authorization for a new action.
