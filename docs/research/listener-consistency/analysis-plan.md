# Proposed analysis plan

Status: planning draft, not a preregistration or validated method.

## Separate measurements

Use blinded discrimination tasks with a defensible correct answer separately from repeated subjective preference comparisons. Randomize presentation order and record EQ pair, track, equipment, protocol and session context. A preference response must not become a listener accuracy label.

Define repeat schedules, handling of ties/nonresponse, primary outcomes, reporting windows and minimum useful precision prospectively. No numerical thresholds or sample-size requirements are established here.

## Subgroups and inference

Define subgroup criteria before examining subgroup preferences. Where possible, use separate trials to measure consistency and estimate preferences, avoiding selection and evaluation on the same outcomes. Examine within-session and between-session repeatability separately.

Report group sizes, comparison exposure, missingness and uncertainty. Preserve participant-level dependence in analysis and resampling. Treat multiple subgroup comparisons as exploratory unless prospectively specified with an appropriate inference plan. Check sensitivity to track, equipment, session, side/order and pair difficulty.

## Weighting

Retain an all-listener analysis as the reference. Treat consistency weighting as a proposed sensitivity analysis requiring validation and an explicit estimand. Describe whose preferences a weighted estimate represents. Do not automatically exclude inconsistent listeners or change current scoring rules.

## Elo-like listener performance

Prototype only on tasks with known answers, such as identifying a controlled stimulus difference. Specify how task difficulty is calibrated, how uncertainty evolves, and how learning and repeated exposure affect estimates. A listener-versus-task rating model requires validation; Elo terminology alone does not establish a valid skill scale.

Compare the score with simpler task-level accuracy and uncertainty summaries. Evaluate synthetic known-performance cases and held-out human observations before any product use. Do not assign errors for subjective taste or infer a universal listening ability from a narrow task.

## Consent and release boundary

Review existing consent coverage before collecting new observations or exposing listener scores. Establish privacy and small-subgroup disclosure rules before aggregate publication. Preserve withdrawal/deletion behavior. This document authorizes no data collection, implementation, public release or historical reweighting.
