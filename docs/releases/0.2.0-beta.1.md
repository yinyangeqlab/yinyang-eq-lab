# YinYang EQ 0.2.0-beta.1

This beta refreshes navigation, listening setup, Personal Tournament, Preference
Tuning, Music Library and My Space while preserving the original colors, AMOLED
curves, waveform controls and keyboard playback. The library loads more tracks
on request; full, icons-only and hidden navigation remain available.

Data choices, account ownership and contribution boundaries are preserved.
No database migration, protected-media change or participant-data import is
included. Listener skill, Golden Ears awards and numerical ranking certainty
are not newly validated or enabled by this release.

The local review passed 43 focused security/account/audio/UI suites, TypeScript,
the production build and protected-media packaging. Vite is patched to 8.1.6.
One upstream braces advisory remains in build/lint tooling; no affected package
was found in emitted runtime modules. CSP script restrictions and HSTS remain
tracked hardening work. This review is not independent penetration testing.

The owner accepted unverified physical headphone output and real Safari/iOS
interruption/recovery coverage on October 21, 2026. Chromium and synthetic
checks do not establish those results. Report issues through the site's beta
notice, excluding private data, sign-in codes and private account links.

The Legacy 0.1 / update103 source/build/media checkpoint is retained. Existing
encrypted off-device recovery is retained; release metadata registration is
separate from a new participant-data export. Exact live status and verification
are recorded after deployment in the current release records.
