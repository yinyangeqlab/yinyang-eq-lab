## Remaining upstream advisory and exposure

The fresh full-tree scan fell from15 high/4 moderate flags to8 high/0 moderate. All eight are affected-package/metavulnerability flags for one upstream `braces` stack-exhaustion advisory, GHSA-vfj7-8cjw-p6xm. The GitHub Reviewed advisory lists versions through3.0.3 as affected and no patched release. Npm's suggested rollback to an older framework/linter was rejected as unsuitable. Do not suppress these flags or imply that all eight are separate vulnerabilities or fixed.

Installed chains are ESLint's Next plugin →fast-glob →micromatch →braces and vinext's build CommonJS/dynamic-import plugins →fast-glob →micromatch →braces. A deeply nested glob supplied to those tools can exhaust the Node process. Do not lint/build untrusted repository contents or pass participant-controlled patterns to this toolchain. No new remote build service or public development server was introduced.

Inspection of the emitted Worker covered224 JavaScript modules and their source maps: none of braces, micromatch, fast-glob, the affected Vite build plugins or ESLint are included, and there are no external imports of those packages. Bare runtime imports are limited to Cloudflare and Node built-ins. The production-only npm scan reports zero flags. This is build-specific evidence supporting a build-tool exposure assessment, not a general proof of non-exploitability; the framework being declared devDependency alone would be insufficient.

Keep the unpatched advisory open and reassess the dependency tree and emitted runtime before release. An upstream patch or replacement should remove the remaining dependency when available; no third-party fork or ad-hoc vendor patch was substituted merely to obtain a clean scanner result.
